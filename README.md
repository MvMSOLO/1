# NEXUS
> Find the part of the web that matters.

NEXUS is an instant interface to the public internet. It optimizes for usefulness by retrieving, deduplicating, organizing, and rendering public web information in an adaptive, transparent experience. It is not a generic link list, a chatbot, or a Perplexity clone, but a new digital medium built around the public internet.

## Getting Started

### Installation
```bash
npm install
```

### Running Development Server
To run both the server-side Cloudflare-compatible endpoint and the React 19 Vite app concurrently:
```bash
npm run dev
```

### Running Tests
To run unit and integration tests:
```bash
npm run test
```

To run Playwright end-to-end tests:
```bash
npm run test:e2e
```
